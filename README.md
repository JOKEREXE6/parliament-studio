# 🏛️ Parliament Studio

Free, interactive web tool for creating clean parliamentary, hemicycle, and election diagrams with instant export to **SVG**, **PNG**, and **JSON**.

👉 **[Launch Parliament Studio Live](https://JOKEREXE6.github.io/parliament-studio/)**

## ✨ Features
- **Custom Layouts:** Hemicycle, horseshoe, full circle, or custom seat distribution.
- **Multi-language UI:** English, Russian, and French support.
- **High-Res Export:** Download crisp vector SVG, high-DPI PNG, or save/load JSON presets.
